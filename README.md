# Traffic Light Simulator

**Production‑ready Spring Boot CLI application** that simulates a traffic light using the Finite State pattern.

## What it does

- Accepts CLI arguments for the duration (in seconds) of **RED**, **AMBER**, **GREEN**, and the total simulation time.
- Prints the current light once per second.
- Enforces business constraints:
  - `AMBER ≤ RED`
  - `AMBER < 33 % of GREEN`
  - `GREEN ≥ 250 % of RED`
  - No direct `GREEN → RED` transition (must go `GREEN → AMBER → RED`).
  - Simulation never ends on GREEN (the final GREEN tick is omitted if it would exceed the total time).
- Uses robust logging (SLF4J + Logback) with configurable log level.

## Architecture overview

```
┌─────────────────────────────┐
│ TrafficLightSimulatorApplication │   (Spring Boot entry point, CLI parsing)
└─────────────▲───────────────┘
              │
┌─────────────┴─────────────┐
│   TrafficLightContext      │   (holds current LightState, durations, timer)
└───────▲───────▲───────▲─────┘
        │       │       │
   ┌────┴────┐ ┌────┴─────┐ ┌─────┴─────
   │ RedState│ │AmberState│ │GreenState│
   └─────────┘ └──────────┘ └──────────┘
        ▲           ▲            ▲
        │                      │
        └───── LightState (interface) ──────┘
```

- **LightState** – core interface (`getColor()`, `getDuration()`, `render()`, `next()`).
- **RedState**, **AmberState**, **GreenState** – concrete implementations.
- **TrafficLightContext** – drives the simulation, handling ticks and state transitions.
- **ValidationUtil** – validates CLI arguments and business constraints.
- **GlobalExceptionHandler** – centralised handling of uncaught runtime exceptions.

## Build & run

### Prerequisites

- Java 17
- Maven 3.9+

### Build the jar

```bash
mvn -q clean package   # produces target/traffic-light-simulator-0.0.1-SNAPSHOT.jar
```

### Run the simulator

```bash
java -jar target/traffic-light-simulator-0.0.1-SNAPSHOT.jar \
  --red 4 --amber 1 --green 10 --total 22 [--log-level DEBUG]
```

- `--log-level` is optional (`DEBUG`, `INFO`, `WARN`, `ERROR`). Default is `INFO`.

### Example output (INFO level)

```
INFO  Starting traffic‑light simulation (total 22 seconds)
INFO  Second 1: RED
INFO  Second 2: RED
INFO  Second 3: RED
INFO  Second 4: RED
INFO  Second 5: GREEN
INFO  Second 6: GREEN
...
INFO  Simulation completed successfully.
```
